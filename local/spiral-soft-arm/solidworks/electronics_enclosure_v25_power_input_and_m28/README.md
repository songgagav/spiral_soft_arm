# B32 v25：电源输入、STM32降压与M28底盖接口

## 本轮修改

v25 继承 v23 三路 M3508 机械结构和 v24 电子仓硬件布局，新增 42×24×5 mm、输入 5–35 V、用户确认额定 20 A 的降压模块，用于 24 V 控制母线向 STM32 提供 5 V。电池继续采用 21700×4、4S1P。

供电逻辑按用户确认记录：PD1002 支持 4S 16.8 V 充电、Type-C 双向充放电、岸电与 Type-C 同时接入，以及外部电源供负载时同步给电池充电；30×16×3 mm 理想二极管用于阻止输入路径回灌。本轮只固定模块关系和空间，不代替实物接线与带载温升试验。

## M28接口

根据用户提供的 WXM M28-2芯/50A 产品图，模型采用：

| 项目 | v25尺寸 |
| --- | ---: |
| 面板异形孔 | 26.2×28 mm |
| 安装圆柱 | Ø27.8 mm |
| 后装内侧法兰 | Ø36 mm |
| 允许面板厚度 | 最大5 mm |
| 插座轴向包络 | 38.5 mm |
| 公插头包络 | Ø33×71.5 mm |
| 适用导体截面积 | 2.5–6.0 mm² |

原底盖厚10 mm。v25在中心接口内侧加工局部沉台，使连接器夹持区保留5 mm材料；Ø36法兰按“后装面板”布置在仓内侧，内侧同时增加内径Ø40、外径Ø56、厚5 mm的一体承力环。开孔由Ø28圆与26.2 mm宽限制面求交形成，避免以普通圆孔代替图片中的双平面开孔。公插头及Ø40×76 mm检修空间用于检查插拔空间，检修空间不导出为实体零件。

## 检查结果

- v25接口与几何测试：9项通过，覆盖降压模块、M28图纸尺寸、5 mm沉台、后装法兰方向、接口和服务包络。
- 14个主要硬件包络之间无非预期体积重叠；新增降压板与v24硬件、仓壁无体积干涉。
- M28沉台探针测得有效材料厚度5.0 mm，开孔包围尺寸26.2×28.0 mm。
- 电子仓STEP和整机STEP均已导出并回读为有效BREP；详细实体数量记录在`装配空间审查.json`。

## 仍未定型

- 产品图没有给出密封圈沟槽、密封压缩量、安装螺母和接线端尾部的完整尺寸，到货后仍需实测。
- 20 A仅为用户提供的模块额定值，未证明其在密封仓内持续输出、温升和效率；STM32实际负载远低于20 A，仍需增加输入保险和端子应力释放。
- 4S40A保护板外形、所有PCB固定孔和端子最高点仍需实测。
- CAN密封穿仓接口、完整线束、底盖O形圈以及5 m水压试验尚未完成。
- 外接M28公插头在底部向下伸出71.5 mm，装配支架和外罩必须保留插拔及电缆弯曲空间。

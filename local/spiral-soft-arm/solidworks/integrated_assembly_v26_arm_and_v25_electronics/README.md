# B32 V26：原机械臂与V25电子仓整合总装

## 版本定位

V26是独立的静态整机整合候选。它直接调用V25组件生成器，把原B32机械臂、燕尾分段、根部顶盘、三路M3508驱动、湿侧线盘、轴封边界和当前电子仓输出为一套总装；没有复制或修改V23、V25的源几何。

## 已整合内容

- 原机械臂：`B32_v10_arm_sections_and_dovetails`，保持5个实体，根面`Z=0 mm`，高度约550.014 mm。
- 三路驱动：60°、180°、300°三组M3508、直角传动、传动轴、轴承/轴封边界和湿侧线盘。
- 根部：250 mm六边形顶盘、根部固定罩和既有三路直线拉索入口。
- 电子仓：完整继承V25的21700×4、三只C620、STM32F407、UPS、24 V稳压器、24→5 V降压板、PD1002、理想二极管、BMS、M28和M12接口布局。

## 静态检查

- 原机械臂仍为5个实体，包围盒和根面与V25来源一致。
- 电子仓主体最高点为`Z=-8 mm`，原机械臂根面为`Z=0 mm`，主体之间保留8 mm坐标间隔；根部连接由顶盘/驱动仓承担。
- 三路驱动前缀和V25必需硬件全部存在。
- `v25_M28_service_clearance`仅作为观察包络，不进入V26物理STEP。
- V26 STEP在导出后重新读入并检查有效BREP，实体数量与整机边界记录在`整机整合审查.json`。

## 仍未验证

本版本只证明静态坐标整合和STEP可读，不证明可直接打印。燕尾榫强度与装配公差、拉索运动/摩擦/回差、根部受力、M28端子和完整线束、电子仓温升、O形圈压缩、水密及5 m压力均需后续实物验证。

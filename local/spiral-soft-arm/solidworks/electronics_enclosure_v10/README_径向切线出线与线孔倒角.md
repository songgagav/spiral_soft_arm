# B32 v10：径向切线出线与线孔倒角

更新：2026-10-22。本目录是 v9 后的独立 CAD 候选，用于检查总装和局部打印件。

## 本轮几何

- 三个顶盘线孔和软臂腱道入口位于俯视角 60°、180°、300°，半径 30.6 mm。对应线盘中心沿同一径向放在半径 96 mm 处。卷绕芯切点到线孔下口的直线在俯视投影中沿对应的牵引径向；线盘转轴与该方向垂直。
- 湿侧 4092 电机代理仍为 Ø42 × 92 mm，水平放置，与线盘同轴。其轴端连接尺寸和卷绕容量仍按代理处理。
- 线孔保留 Ø4.2 mm 通孔；顶盘上下两面均切出深 0.8 mm、入口 Ø5.8 mm 的 45° 倒角。此处是孔口几何倒角，不是带确定最小弯曲半径的导轮。
- 三条直线自由段的模型长度相同，约 68.759 mm。电子仓顶部与第一条拉索代理的静态间隙约 1.675 mm，电机与电子仓的最小静态距离约 7.24 mm。
- 为避开径向拉索，将电子仓顶端三只盲孔安装柱与顶盘配孔转位到 0°、120°、240°；包覆件的电机检修窗与上缘固定耳同步改位。

## 审核边界

部分电机包络超出 250 mm 顶盘的平面轮廓，后续需依据实物电机外形核对支架、搬运和外罩空间。1.675 mm 的仓顶静态间隙不足以代表实际线缆晃动、公差和受力余量。倒角可减少孔口锐边，但拉索进入臂内腱道时的动态接触、磨损和最小弯曲半径尚待实体试样确认。

生成脚本完成了三段高度、静态干涉、预览、STEP 回读和 STL 网格拓扑检查；这不等于切片、打印、水密或水下运行放行。

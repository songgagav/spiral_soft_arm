# B32 v15：竖装电机与水平线盘轴

本版修正 v14 中电机轴与线盘轴平行的问题。三台 DJI M2006 P36 仍竖装于共用干仓，电机上方各有一只与干仓顶盖静密封连接的小型干式直角传动舱。线盘轴在俯视图中沿各自拉索方向的**切向**水平布置，与电机竖直轴成 90°，也与拉索的径向投影垂直。三根拉索从卷芯切点沿各自一条直线进入 250 mm 六边形顶盘的倒角线孔，不增加导向轮。

原先提出的“线盘轴线沿机械臂弯曲径向”与“拉索从卷筒切点沿同一径向直达线孔”不能同时成立。用户本轮选择保留后者，因此 v15 采用切向线盘轴。轴线方向、出线方向和直角传动舱均在 STEP 中单独表达。

## 主要结构

| 部位 | v15 候选布置 |
| --- | --- |
| 电机 | 三台 M2006 P36，竖直轴；厂商外形包络 Ø24.4 × 64.8 mm、Ø6 mm 输出轴 |
| 电机安装 | 19 mm PCD 三处 M3 转接孔；三根间隔柱连接顶盖 |
| 传动 | 电机经干侧联轴器、竖轴及顶盖轴承进入各自干式直角传动舱；舱内预留 90° 齿轮空间 |
| 线盘轴 | Ø8 mm 水平独立轴，沿俯视切向；舱内轴承支撑，穿过水平骨架油封后连接湿侧线盘 |
| 线盘 | 卷芯半径 6.5 mm，双侧挡边半径 10.5 mm；轴线位于 z = −23 mm |
| 直角传动舱 | 外径 37 mm，顶端距六边形顶盘底面 2 mm；底座和顶盖各有静密封圈占位及螺钉孔 |
| 电子件 | 电池架、STM32 和 UPS 分别横向调整，给新电机与转接板让出空间 |

线盘与顶盘之间保留直线拉索段。审计使用半径 0.8 mm 的**拉索空间代理**；它的中心线与卷芯外加该代理半径后的有效圆相切，使索体不穿过卷芯。该半径不是已选购拉索的标称尺寸。三处顶盘孔继续采用 Ø4.2 mm 通孔、双面 1.5 × 45° 倒角，并与真实臂根通道对齐。第 6、第 13 关节内部燕尾榫分段保持不变。

直角传动舱以打印壳体、顶盖、底座静密封圈、水平轴骨架油封和轴承的尺寸代理展示。**实际直角齿轮副尚未选型**，红色齿轮空间仅在预览中显示，不作为实心齿轮导入 STEP。这是为了避免把未经选型的齿形伪装成可加工件。齿轮外径、模数、轴向定位、润滑、轴向止推、油封压装尺寸和轴表面状态必须根据实物重新定型。舱盖目前为 2 mm 厚几何候选，静密封圈位置仅供布局审查；其 5 m 水深承压能力未计算或验证。

## 装配与验证范围

候选装配顺序：在共用干仓顶盖安装电机转接板和竖轴轴承；安装直角传动舱底座及静密封；装入实际齿轮副与水平轴承、水平轴封；合上舱盖；再装湿侧线盘和六边形顶盘。六根顶盘支柱移开传动舱方位，底盖保留电子件检修。实际装配工具可达性与维修拆卸次序仍需样件确认。

`装配布置审计.json` 检查三路拉索切线误差、线孔与真实臂根通道、线盘/传动舱/顶盘/支柱、主要电子件及安装支撑的实体相交，以及各独立打印件的 350 × 350 × 250 mm 包络。舱体与静密封圈的轻微预压代理属于有意接触。静态 CAD 检查不证明齿轮传动、密封寿命、材料强度、线束弯曲半径或实际打印可行性；本版仍是**待定型布局候选**。

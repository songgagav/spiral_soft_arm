# B32 水下三缆软臂原型打印资料包

本资料包包含 B32 软臂原模型、TPU 工艺短样、三路湿侧安装件的 9 个独立 STL、装配 STEP、参数/验收资料，以及打印和实物试验记录表。建议先阅读 `docs/打印前与实物实验指南.md`。

打印文件默认按毫米和 100% 比例导入。先处理两个 80 mm TPU 工艺短样。湿侧托座按 4092 电机包络估算，实际电机接口和线轮轴系尚未测量确认；托座 STL 供配合打样，电机和线轮本身不在打印文件中。当前模型不构成生产放行或水下压力认证。

文件夹说明：`models/` 放打印/装配模型，`docs/` 放参数和工艺资料，`forms/` 放实测记录表。`SHA256SUMS.csv` 列出本资料包各文件的 SHA-256 校验值。

参考研究中的 TPU 外置供料、引导穿线、冷却后形态基线和逐路松弛校准已整理进[打印工艺要求](docs/打印工艺要求.md)及[打印过程记录表](forms/打印过程记录模板.csv)，参数需由 B32 短样和台架测量确定。

外部软臂 STL、3MF 切片工程及分件样例的文件哈希、参数和适用边界见[《外部模型参考与迁移审查》](docs/外部模型参考与迁移审查.md)。该文档用于参考资料追溯，不代表将外部几何迁入 B32 或 3.0。

第二阶段的网格边界、3MF 单位/变换及轴向截面数值预检见[《外部模型几何与 3MF 预检》](docs/外部模型几何与3MF预检.md)。该结果是数字网格审查，不替代 CAD 可视检查、切片器复核或实物打印。
